Technician App: Service Expert + Delivery Executive
Empowering local handymen into certified delivery and installation entrepreneurs
BharathFix • Confidential Client Presentation • 2026
Role A: Service & Repair Technician
1. Receive skill-matched job alert via push notification
2. Review customer address & launch Google Maps navigation
3. Arrive at doorstep & verify 4-digit Start OTP
4. Inspect machine & build digital quote (spares + labor)
5. Customer approves quote on their own phone
6. Complete repair, verify Completion OTP, collect fee
Role B: Delivery & Installation Executive
1. Receive new appliance delivery & installation order
2. Navigate to BharathFix hub/store to collect boxed item
3. Mark "Picked Up" & drive to customer location
4. Unpack, mount (wall/pipe/socket), and install appliance
5. Power on, test, and conduct live customer demonstration
6. Customer inputs Delivery & Demo OTP to close order

Production Readiness & Technical Safeguards
Audited technical improvements to ensure high availability and financial security
BharathFix • Confidential Client Presentation • 2026
🛡️ Server-Side Razorpay Order Creation
Vulnerability: Client-side mock order IDs cause immediate payment rejections in live mode.
Production Fix: Backend Node.js API creates genuine Razorpay order IDs with live currency and secret keys.
🛡️ HMAC-SHA256 Webhook Verification
Vulnerability: Public webhook could allow bad actors to spoof payment success callbacks.
Production Fix: Cryptographic signature verification ensures only verified Razorpay payment webhooks update order status.
🛡️ Localized Database Query Scoping
Vulnerability: Global query fetched all bookings across entire database on every date selection.
Production Fix: Filtered queries scoped by city/taluk and service category. Saves 99% Firestore read costs.
🛡️ 24/7 Always-On Push Engine
Vulnerability: Free-tier backend server sleeping caused missed push notifications for technicians.
Production Fix: Production cloud host (AWS/DigitalOcean/Paid Render) with FCM v1 daemon keeps alerts active 24/7.
